Honest Restraint

When evidence is insufficient, DocLink says so.

Most RAG systems fabricate plausible-sounding answers from thin context. DocLink measures retrieval confidence against an explicit threshold and abstains rather than hallucinate. This is the actual API response to a question with no supporting documents.

Architecture

A linear pipeline with a gate before generation.

Every query passes through retrieval, cross-encoder reranking, and an explicit abstention gate before the language model is invoked. The LLM never sees a query that lacks evidence. Citations are programmatic, not generated.

Ingest
PDF, DOCX, images, audio. Extract + chunk.
→
Embed
384-d vectors. FAISS exact search.
→
Rerank
Cross-encoder scoring. Top-K filter.
→
Gate
Abstain if score < threshold. No hallucination.
→
Generate
Grounded answer. Programmatic citations.
